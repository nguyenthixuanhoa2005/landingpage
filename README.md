# Tea Tree Essential Oil MVP Ecommerce

A complete MVP frontend for a tea tree project landing page + online shop.

Tech stack:
- React + Vite
- Tailwind CSS
- Supabase (Auth + orders storage)
- LocalStorage (shopping cart persistence)

## Features Implemented

1. Landing page:
- Hero section with premium tea tree branding
- Introduction, benefits, and applications
- Production process section
- Featured products
- Clear CTA to shop

2. Shop:
- Product grid from mock data
- Product cards (image, name, price, description)
- Add to cart action

3. Cart:
- Add/remove items
- Update quantity
- Auto total calculation
- Persisted in LocalStorage

4. Authentication (Supabase Auth):
- Register account
- Login account
- Logout
- Checkout route protected by login

5. Checkout:
- Requires login
- Form fields: full name, phone number, address
- COD only
- Order summary display
- Save orders to Supabase table

6. UI/UX:
- Responsive desktop/tablet/mobile
- Natural green premium visual style
- Smooth entrance motion
- Reusable component-based structure

## Setup Guide

### 1. Install dependencies

```bash
npm install
```

### 2. Create environment file

Create a `.env` file in the project root:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Get both values in Supabase Dashboard:
- Project Settings
- API

### 3. Create Supabase orders table

Run this SQL in Supabase SQL Editor:

```sql
create table if not exists public.orders (
	id bigint generated by default as identity primary key,
	created_at timestamp with time zone default now() not null,
	user_id uuid not null references auth.users(id) on delete cascade,
	full_name text not null,
	phone_number text not null,
	address text not null,
	payment_method text not null default 'COD',
	total_price numeric not null,
	order_items jsonb not null,
	status text not null default 'pending'
);

alter table public.orders enable row level security;

create policy "Users can insert own orders"
on public.orders
for insert
to authenticated
with check (auth.uid() = user_id);

create policy "Users can view own orders"
on public.orders
for select
to authenticated
using (auth.uid() = user_id);
```

### 4. Configure Supabase Auth

In Supabase Dashboard:
- Authentication
- Providers
- Enable Email provider

Optional (for easiest MVP testing):
- Authentication
- Providers
- Disable email confirmation temporarily

If email confirmation stays enabled:
- User must confirm email before login.

### 5. Run app

```bash
npm run dev
```

Open the URL shown by Vite.
